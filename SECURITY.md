# Sicherheit

Lagekit läuft vollständig im Browser und speichert alle Daten lokal. Trotzdem können Fehler die Daten gefährden, etwa durch einen manipulierten Import oder eine Lücke in einer Abhängigkeit.

## Melden

Bitte melden Sie Sicherheitsprobleme **vertraulich** über [GitHub Security Advisories](https://github.com/sebiweise/lagekit/security/advisories/new), nicht als öffentliches Issue. Beschreiben Sie, wie sich das Problem nachstellen lässt, und schicken Sie keine echten Einsatzdaten mit.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste Version.
